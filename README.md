# colorgolf

A color matching game. Play it: **https://dglittle.github.io/colorgolf/**

A color is shown at the top. Build it from shades of red, green and blue (7 shades each),
then swing. You see how many "shades away" you are. You get 6 tries per color, 9 colors per
game, and your score is the total number of tries. Like golf, lower is better. A color matched
on the first try is a hole in one, and earns a star in that color.

The whole game is one file, `index.html`, with no dependencies. Your games are saved in localStorage.

## History
- 2014: the first version, a web page: [dglittle/color-golf](https://github.com/dglittle/color-golf). About 5000 people played it.
- 2025: an iPhone app (SwiftUI), briefly on the App Store.
- 2026: this version, the iPhone app's game ported back to a single web page.
